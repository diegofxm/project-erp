Propuesta de diseño · Cofacture ERP

Contabilidad primero: un sistema visual que se ve como un ERP, no como un panel de base de datos.

Se conserva la estructura actual (navbar arriba + sidebar izquierda). Lo que cambia es el lenguaje visual del contenido — inspirado en los patrones de Odoo: pestañas de formulario, botones-stat, barra de estado, tarjetas kanban y listas con barra de herramientas real — empezando por Contabilidad, el módulo que termina conectando a todos los demás.

Ver el panel de contabilidad → Ver un asiento con pestañas

Por qué cambiar

El diseño actual del frontend se heredó literalmente de DBPanel, un cliente de base de datos tipo pgAdmin (documentado en docs/reference/DESIGN_SYSTEM.md): 13px de fuente base, radios de 4px, cero jerarquía tipográfica, paleta de "herramienta de administrador". Funciona para inspeccionar tablas SQL — no comunica confianza para un sistema donde alguien firma asientos contables y factura electrónicamente ante la DIAN.

Hoy — heredado de un cliente SQL

  • Base de 13px, casi todo text-xs
  • Radios de 4px, sin jerarquía de tamaños
  • Un solo azul de acento, sin identidad propia
  • Tablas densas sin agrupación ni herramientas
  • Sin patrón de pestañas para formularios largos

Propuesta — mismo navbar/sidebar, azul oscuro

  • Misma base de 13px, mismo navbar h-10 y sidebar w-48/w-10
  • --navbar-bg y --accent-primary pasan a azul oscuro
  • Semántica (éxito/alerta/peligro) sin tocar, sigue igual
  • Listas con grupos colapsables, barra de filtros
  • Notebook de pestañas + botones-stat + status bar (nuevo, para Contabilidad)

Qué trae la propuesta

Piezas nuevas de UI, pensadas para reutilizarse en todos los módulos futuros (ventas, compras, inventario, nómina), no solo en contabilidad.

Notebook de pestañas

El sello de Odoo: un registro largo (asiento, factura, empleado) se organiza en pestañas horizontales en vez de un formulario interminable. Ver journal-entry.html.

Botones-stat y status bar

La cabecera de un registro muestra sus métricas clave (líneas, adjuntos) como botones, y su estado como una barra de pasos — no solo un badge suelto.

Tarjetas kanban de resumen

El panel de cada módulo (empezando por Contabilidad) resume sus "diarios" como tarjetas con cifra, tendencia y accesos directos — igual que el dashboard de Odoo Accounting.

Listas con jerarquía real

Agrupación colapsable por clase de cuenta, barra de filtros/búsqueda, columnas numéricas en monoespaciada alineada — ver chart-of-accounts.html.
